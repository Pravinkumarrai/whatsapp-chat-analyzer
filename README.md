# whatsapp-chat-analyzer
The WhatsApp Chat Analyzer is a data analysis project that extracts meaningful insights from exported WhatsApp chat data.
It processes chat messages and provides various statistics, visualizations, and patterns that help users understand communication behavior within a conversation.
The project also includes activity heatmaps, which visually represent message frequency across different days of the week and hours of the day. This makes it easier to understand when the chat is most active.
